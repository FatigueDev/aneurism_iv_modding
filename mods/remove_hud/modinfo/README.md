## Remove Hud

Some fates currently have disorienting / constraining visual effects that make it hard to see and prolonged exposure to viewing can cause nauseua or outright make the game unplayable for those with eyesight issues.

This mod removes those visual effects (default: disable overlay, toggle key `N`), which makes it a good tool for screenshots as well (remove the base UI elements with `H`, which is already in the game to achieve this).
